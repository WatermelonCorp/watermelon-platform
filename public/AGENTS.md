# Watermelon UI for coding agents

Watermelon UI is a free, open-source catalog of React components, animated
components, blocks, dashboards, and templates for Tailwind CSS and shadcn/ui.

## Find a component

- MCP server (no API key): https://mcp.watermelon.sh/mcp (Streamable HTTP)
- Catalog API: https://ui.watermelon.sh/api/v1/catalog/summary and
  https://ui.watermelon.sh/api/v1/catalog/entries?kind=blocks
- API reference: https://ui.watermelon.sh/openapi.json
- Site guide: https://ui.watermelon.sh/llms.txt

The home, about, contact, legal, and developers pages also answer
`Accept: text/markdown` with a markdown version.

## Install a component

Each catalog entry has an `installCommand` for the shadcn CLI. Run it in a
project that already has shadcn/ui set up. See
https://ui.watermelon.sh/installation.
